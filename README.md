# Musqet Merchant for Android

This repository holds the [Zapstore](https://zapstore.dev) listing for **Musqet Merchant**, the merchant app for [Musqet](https://musqet.com). The app's source code is private; releases are published to Zapstore by Musqet's Nostr identity:

`npub1musqetp57matzsjcwd2y7tvxe59h85v74pqasnqxk7fhpwazzjpseyv5kr`

Musqet Merchant is also available on Google Play and TestFlight. The Zapstore build is signed with a different key from the Google Play build, so one cannot update the other: to move between the two, uninstall first, and make sure your wallet's recovery phrase is written down.
